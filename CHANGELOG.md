# Changelog

## 1.0.0

First release.

- Key actions: Power, Set Brightness, Adjust Brightness, Set Temperature, Adjust Temperature, Set Color, Preset, Battery, Identify, Scan.
- Stream Deck+ dials: Brightness and Temperature, with live touch-strip readouts.
- Keys render live from the daemon state, so they reflect changes made from any other app.
- Bundles keylightd and starts it when nothing is listening on the daemon port.
- Linux x86_64 and aarch64 builds.
